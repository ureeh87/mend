mend: one patch tool for every AI edit format. It applies the edits AI models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON patches — to a tree of files, atomically: either every edit applies or nothing changes. Node 22 standard library only, deterministic. Built for the make.fun bounty "Build mend, one patch tool for every AI edit format". See SPEC.md for the full specification.

## Run it

```sh
node main.ts [options] [PATCH]
```
